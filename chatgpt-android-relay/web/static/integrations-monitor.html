새 프로그램 연결 방법

전체 API 사용법

새 프로그램이 대화방을 열 때 service_id를 함께 보내면 프로그램별로 자동 구분됩니다. 같은 이름의 대화방을 다른 프로그램에서도 독립적으로 사용할 수 있습니다. 기존 API 호출을 변경하지 않아도 동작합니다.

POST /integrations/v1/public/rooms
{"name":"일반 대화방","service_id":"service-alpha"}

POST /integrations/v1/public/chat
{"room_name":"일반 대화방","service_id":"service-alpha","text":"질문 내용"}

계정 연결형 API는 개인별 대화 내용 없이 전체 집계만 표시합니다.
