HITEL ChatGPT 공개 API — 대화방 유지 사용방법

로그인·API 키·GitHub 수동 실행 없이 링크만으로 사용합니다. 가장 먼저 대화방 이름을 선택하고, 그 방에서 질문을 계속하십시오. 같은 이름이면 기존 대화방을 재사용합니다. 다른 이름이면 다른 방으로 전환합니다. 명시적으로 새 방을 요청한 때에만 신규 대화방을 생성합니다.

바로 질문하기 (웹 화면)

1. 기존 대화방 찾기

GET https://hitel-integration-api-production.up.railway.app/integrations/v1/public/rooms

현재 공개 API를 통해 생성된 대화방의 room_name과 room_id를 반환합니다.

2. 기존 방 열기 또는 처음 생성하기

POST https://hitel-integration-api-production.up.railway.app/integrations/v1/public/rooms
Content-Type: application/json

{"name":"수학 교재 분류"}

이름이 이미 있다면 기존 room_id를 반환합니다. 처음 사용하는 이름이라면 새 방을 한 번 생성합니다. 반환된 ID를 이후 질문에 계속 사용하십시오.

{"room_id":"room_실제32자리ID","room_name":"수학 교재 분류",
 "created":false,"conversation_linked":true,"status":"active"}

위 JSON은 응답 형식 예시입니다. conversation_linked=true이면 기존 ChatGPT 대화방 주소가 저장되어 있다는 뜻입니다.

3. 같은 대화방에서 질문 계속하기

POST https://hitel-integration-api-production.up.railway.app/integrations/v1/public/chat
Content-Type: application/json

{"room_id":"room_실제32자리ID","text":"첫 질문입니다."}

HTTP 202 응답에서 job_id를 얻습니다. 이때 방 ID는 바꾸지 마십시오.

GET https://hitel-integration-api-production.up.railway.app/integrations/v1/public/jobs/<job_id>

status=completed인 경우 result_text를 사용합니다. queued 또는 running이면 조회를 반복합니다. 직전 질문의 완료를 확인한 뒤 다음 질문을 같은 room_id로 보내십시오.

이전 방 이름만 보내셔도 됩니다.

POST /integrations/v1/public/chat
Content-Type: application/json

{"room_name":"수학 교재 분류","text":"앞서 분류했던 5개 중 2번을 다시 설명해 주세요."}

같은 이름은 기존 ChatGPT conversation_id로 연결됩니다.

4. 다른 방으로 전환할 때

POST /integrations/v1/public/rooms
Content-Type: application/json

{"name":"영어 교재 분류"}

이전 이름과 다르면 다른 방을 선택하거나 처음 만들어 줍니다. 반환된 새 room_id를 사용합니다. 나중에 다시 수학 교재 분류로 바꾸면 그 방의 기존 대화로 돌아갑니다.

5. 새 방을 명시적으로 만들 때에만

POST /integrations/v1/public/rooms
Content-Type: application/json

{"name":"수학 교재 분류","create_new":true}

이때에만 같은 이름으로 새로운 대화방을 만들어 반환합니다. 기존 방은 삭제하지 않고 예전 room_id로 계속 참조할 수 있습니다. 다만 그 이름으로 다시 열면 가장 최근에 명시적으로 생성한 방이 선택됩니다.

6. 완성된 Python 예시

import time
import uuid
import requests

BASE="https://hitel-integration-api-production.up.railway.app"
NAME="수학 교재 분류"
session=requests.Session()

# 1. 같은 이름이면 기존 방을 열어 계속 사용합니다.
r=session.post(BASE+"/integrations/v1/public/rooms",
               json={"name":NAME},timeout=30)
r.raise_for_status()
room_id=r.json()["room_id"]

def ask(text):
    # 2. 같은 방의 이전 질문이 완료된 뒤 호출하십시오.
    request_id="req_"+uuid.uuid4().hex
    r=session.post(BASE+"/integrations/v1/public/chat",
                   json={"room_id":room_id,
                         "text":text,
                         "request_id":request_id},timeout=40)
    r.raise_for_status()
    job_id=r.json()["job_id"]
    while True:
        r=session.get(BASE+"/integrations/v1/public/jobs/"+job_id,
                      timeout=30)
        r.raise_for_status()
        result=r.json()
        if result["status"]=="completed":
            return result["result_text"]
        if result["status"]=="failed":
            raise RuntimeError(result.get("error") or "작업 실패")
        time.sleep(3)

print(ask("중학교 1학년 수학 교재를 분류해 주세요."))
print(ask("방금 분류한 교재 가운데 2번을 다시 설명해 주세요."))

이 코드는 두 질문 모두 동일한 대화방으로 전송합니다. Python requests 라이브러리가 필요합니다.

7. 기존의 간편 호출과 자동 기동

기존의 {"text":"질문"}만 보내는 호출도 계속 지원합니다. 이 경우 매번 새 방을 만들지 않고 기본 대화방을 재사용합니다. 워커가 꺼져 있으면 서버가 기존 GitHub 실행 설정을 통해 자동 시작을 시도합니다.

HTTP 202는 접수만 뜻합니다. 오류가 났을 때 동일 질문을 새 요청 ID로 무작정 재전송하지 마십시오. 실제 완료 여부는 작업 조회로 판단하십시오.

8. 공개 이용 안내

이 링크는 로그인 없는 공용 시험 환경입니다. 같은 이름의 방을 다른 이용자도 선택할 수 있으므로 공개되어도 무방한 시험 자료만 사용하십시오. 기존 개인 비공개 ChatGPT 방을 이름만으로 검색하여 열어 주는 기능은 아닙니다. 외부 파일 첨부·다운로드 API는 아직 지원하지 않습니다.
