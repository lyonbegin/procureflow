HITEL — 로그인 없이 사용하는 ChatGPT 시험 API

**누구나 URL만으로 사용할 수 있는 공개 시험용 API**입니다. GitHub 계정, 로그인, HITEL API 키, ChatGPT 계정 ID가 필요하지 않습니다.

웹에서 바로 사용: https://hitel-integration-api-production.up.railway.app/integrations/public

외부 프로그램 호출 방법

기본 주소: https://hitel-integration-api-production.up.railway.app

1. 다음 URL에 POST로 JSON 질문을 보내십시오.

POST /integrations/v1/public/chat
Content-Type: application/json

{"text":"안녕하세요. 한 문장으로 답변해 주세요."}

요청은 로그인 없이 접수됩니다. HTTP 202가 반환되며 job_id를 받습니다. 워커가 꺼져 있어도 서버가 자동으로 기동을 시도합니다.

2. 반환받은 job_id로 결과를 조회하십시오.

GET /integrations/v1/public/jobs/<job_id>

status=completed이면 result_text가 실제 답변입니다. queued 또는 running이면 같은 주소를 다시 조회하십시오. failed라면 error를 확인하십시오.

Python 예제

import time
import requests

base = "https://hitel-integration-api-production.up.railway.app"
r = requests.post(
    base + "/integrations/v1/public/chat",
    json={"text": "연결 확인입니다. 간단히 답변해 주세요."},
    timeout=30,
)
r.raise_for_status()
job_id = r.json()["job_id"]

while True:
    result = requests.get(
        base + "/integrations/v1/public/jobs/" + job_id,
        timeout=30,
    )
    result.raise_for_status()
    data = result.json()
    if data["status"] == "completed":
        print(data["result_text"])
        break
    if data["status"] == "failed":
        raise RuntimeError(data.get("error") or "ChatGPT job failed")
    time.sleep(3)

Python 예제는 requests 라이브러리가 설치되어 있다고 가정합니다.

cURL 예제

curl -sS -X POST \
  "https://hitel-integration-api-production.up.railway.app/integrations/v1/public/chat" \
  -H "Content-Type: application/json" \
  --data '{"text":"안녕하세요. 답변해 주세요."}'

반환된 job_id를 아래에 넣어 조회하십시오.

curl -sS \
  "https://hitel-integration-api-production.up.railway.app/integrations/v1/public/jobs/<job_id>"

참고 사항

질문마다 새 대화가 생성되며, 기존 비공개 대화방 조회나 이전 대화 목록 접근은 제공되지 않습니다. 질문의 중복 접수를 방지하려면 요청에 고유한 request_id (영숫자·점·밑줄·하이픈·콜론 16~128자)를 선택적으로 넣으십시오.

파일 첨부·생성 파일 다운로드는 현재 미지원입니다. HTTP 202는 질문 접수일 뿐, 실제 완료는 결과 조회에서 확인해야 합니다. 누구나 이용 가능한 공개 링크이므로 실제 ChatGPT 계정의 사용량에 영향을 줄 수 있습니다.
