연결 유지 신호(heartbeat)는 실제 답변 진행 증거가 아닙니다.

  1. 작업 접수 → GitHub Chrome 작업자 수신
  2. ChatGPT 탭·입력창 확인 → 질문 입력 및 전송
  3. 새 사용자 메시지 확인 → 새로운 assistant 응답 발견
  4. 응답 완료 검증 → Railway에 최종 답변 저장

전송 확인이 '미확인'인 동안 재전송하지 마십시오. unknown 또는 stalled은 질문 미전송이 아니라 전송 결과가 불명확하다는 뜻일 수 있습니다.
