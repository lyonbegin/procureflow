작업자 실행 / 다시 켜기

GitHub Chrome 작업자 실행 화면 열기

  1. GitHub 페이지의 Run workflow를 누르십시오. GitHub 권한이 있는 계정으로 로그인되어 있어야 합니다.
  2. operation=worker_only가 기본 선택이고, run_minutes=240(4시간)이 기본값입니다. 기존 계정 연결코드는 비워 두시면 됩니다.
  3. Run workflow를 확정하시면 Chrome 로그인 확인 후 작업자가 신규 Railway API WebSocket에 연결됩니다.
  4. 이 페이지로 돌아오시면 상태가 자동 갱신됩니다. worker_connected=true가 확인된 다음 다른 앱에서 질문을 보내십시오.

이 링크를 열기만 해서는 GitHub Action이 시작되지 않습니다. GitHub의 인증된 실행 확인 클릭이 필요합니다. GitHub 토큰이나 로그인 비밀번호를 이 웹페이지에서 수집하지 않습니다.

외부 프로그램 연동

작업자가 연결된 동안 기존에 발급받은 htli_ 인증키와 oai_ 계정 ID로 텍스트 채팅 API를 호출할 수 있습니다. 종료 후에는 이 링크로 다시 실행하십시오.

해당 API에는 시간당 5건 및 하루 전체 30건의 임의 호출 제한을 두지 않습니다. 작업자 처리 능력과 ChatGPT 서비스 자체의 제한은 별개입니다.
