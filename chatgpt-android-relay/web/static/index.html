01. 인증 및 사용자 API Client

인증되지 않았습니다. 기존 관리자 토큰이나 사용자 API Key를 입력해 주십시오.
이 테스트 페이지에는 요청하신 기존 기본값이 미리 입력됩니다. 별도 입력 없이 API 테스트를 시작하실 수 있습니다.
관리 토큰은 테스트 관리 기능에 사용합니다. 사용자 API Key가 있으면 해당 사용자 자신의 채팅방에만 접근합니다.
시험용 API 콘솔입니다. 파일 업로드 시 사용자별 API Key를 권장합니다. 관리자 토큰은 웹 소스에 포함하지 않고 이 브라우저에만 저장합니다. 운영 환경에는 별도 로그인 및 권한 관리가 필요합니다.

02. 채팅방 엔드포인트 Rooms

POST/api/v1/rooms
주소창의 https://chatgpt.com/c/... 개인 대화 URL을 등록하십시오. 공유 스냅샷인 /share/...는 해당 채팅방에 메시지를 보낼 수 없어 사용할 수 없습니다. URL을 설정하면 다음 메시지부터 Android가 딥링크로 해당 대화를 엽니다.
기존 방을 찾지 못하면 휴대폰의 공식 ChatGPT에서 해당 대화를 직접 한 번 열고 위 연결 버튼을 누르십시오. 해당 대화에 고유 연결 메시지 1개를 전송하여 이후부터 자동 검색할 수 있도록 등록합니다. 다른 채팅방이 열려 있으면 연결하지 마십시오.
방을 선택하면 연결된 ChatGPT 고유 URL을 Android로 전달하고 해당 대화를 엽니다. URL이 없으면 실제 제목·과거 메시지로 검색합니다.
채팅방 목록이 여기에 표시됩니다.
삭제는 Android의 실제 삭제가 확인되어야 완료됩니다. 삭제 실패 시 상태를 유지합니다.

03. 파일 + 질문 Railway → Android

파일을 선택하지 않으셨습니다.
기존에 업로드한 파일을 다시 사용하시려면 체크박스로 선택하십시오.
웹에서 Railway로 파일을 올리고 Android 릴레이 앱이 HTTPS로 다운로드합니다. 이어서 공식 ChatGPT의 첨부 메뉴에서 파일을 선택해 미리보기가 확인되면 질문을 보냅니다. Google Drive는 사용하지 않습니다.
