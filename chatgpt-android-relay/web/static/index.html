01. 인증 및 사용자 API Client

Drive 상태 조회·계정 연결 전에는 관리 토큰 또는 사용자 API Key 인증이 필요합니다. 인증 정보는 공개 웹 소스에 포함하지 않습니다.
관리 토큰은 테스트 관리 기능에 사용합니다. 사용자 API Key가 있으면 해당 사용자 자신의 채팅방에만 접근합니다.
시험용 API 콘솔입니다. Google Drive에 개인 파일을 올릴 때에는 각 사용자 API Key를 권장합니다. 관리자 토큰은 웹 소스에 포함하지 않고 이 브라우저에만 저장합니다. 운영 환경에는 별도 로그인 및 권한 관리가 필요합니다.

03. Google Drive 파일 전송 파일 링크

Google Drive를 새 창으로 열어 파일을 올린 후 공유 링크를 복사해 주십시오.
Google Drive 열기 → 파일 올리기 → 공유 링크 복사 → 아래에서 링크 등록
링크 공유를 허용하면 링크를 아는 사람이 파일에 접근할 수 있습니다.
저장된 파일이 여기에 표시됩니다.
Drive 링크를 ChatGPT 질문에 전달합니다. 실제 파일을 열어볼 수 있는지는 ChatGPT에서 확인해야 합니다.
POST/api/v1/rooms/{room_id}/messages
Android에서는 파일 첨부(+ 버튼)를 사용하지 않습니다. Drive 링크를 텍스트로 전달합니다. 링크만으로 ChatGPT가 이미지 내용을 읽는다고 보장할 수는 없습니다.
