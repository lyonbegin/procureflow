01. 인증 및 사용자 API Client

인증되지 않았습니다. 기존 관리자 토큰이나 사용자 API Key를 입력해 주십시오.
Railway의 chatgpt-relay-web → Variables → CONSOLE_TOKEN에 등록된 관리자 값을 한 번 입력하시면 이 브라우저에서 다시 사용할 수 있습니다. 해당 값이 비공개라 확인할 수 없다면 Railway 관리자 권한으로 새 값을 설정해야 합니다. Android 기기 토큰은 여기에 넣지 마십시오.
관리 토큰은 테스트 관리 기능에 사용합니다. 사용자 API Key가 있으면 해당 사용자 자신의 채팅방에만 접근합니다.
시험용 API 콘솔입니다. 파일 업로드 시 사용자별 API Key를 권장합니다. 관리자 토큰은 웹 소스에 포함하지 않고 이 브라우저에만 저장합니다. 운영 환경에는 별도 로그인 및 권한 관리가 필요합니다.

03. 파일 + 질문 Railway → Android

파일을 선택하지 않으셨습니다.
기존에 업로드한 파일을 다시 사용하시려면 체크박스로 선택하십시오.
웹에서 Railway로 파일을 올리고 Android 릴레이 앱이 HTTPS로 다운로드합니다. 이어서 공식 ChatGPT의 첨부 메뉴에서 파일을 선택해 미리보기가 확인되면 질문을 보냅니다. Google Drive는 사용하지 않습니다.
