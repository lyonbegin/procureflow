2. 계정 연결코드 발급

아래 버튼을 누르시면 15분 동안 한 번만 사용 가능한 코드가 발급됩니다. 이 코드를 GitHub Actions에 입력하시면 저장된 Chrome 계정의 실제 로그인 일치 검증 후 현재 브라우저에 계정이 연결됩니다. ChatGPT 비밀번호나 로그인 쿠키를 입력하지 않습니다.

GitHub Actions에 붙여 넣으실 연결코드



서명된 GitHub Actions 계정 검증 워크플로를 열고 Run workflow에서 pairing_code 필드에 위 코드를 넣으신 뒤 실행하십시오. 성공한 후 이 페이지에서 상태 다시 확인을 눌러주십시오.
