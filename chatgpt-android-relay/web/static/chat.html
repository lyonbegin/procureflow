브라우저용 대화 기록을 준비하고 있습니다.
자유 질문 전송은 브라우저별 시간당 5회, 전체 사이트 일일 30회로 제한됩니다. 파일 업로드·열람은 가능하나 PDF·이미지를 ChatGPT에 직접 첨부하는 기능은 아직 지원되지 않습니다. 별도 토큰 입력은 없습니다.

새 대화방

방 이름을 입력해 주십시오. 다른 방문자의 대화는 표시되지 않습니다.

실제 ChatGPT 계정 연결

Google로 가입하신 계정도 공식 OpenAI 인증을 완료해야 이 목록에 표시됩니다. 기존 ChatGPT 앱의 계정 목록이 HITEL에 자동 복사되지는 않습니다.

인증 상태를 확인하고 있습니다.

HITEL의 공식 로그인은 OpenAI에서 발급하는 웹사이트용 OAuth 클라이언트가 필요합니다. 공식 클라이언트 등록 안내 · 인증 전에는 실제 ChatGPT 계정명을 확인하거나 GitHub Chrome 로그인으로 사용할 수 없습니다.

ChatGPT 계정의 인증과 실제 메시지 실행 권한은 다릅니다. 신원 인증만 완료된 계정을 기존 GitHub Chrome의 다른 계정 세션으로 실행하지 않습니다. 비밀번호·Google 인증 코드·쿠키를 HITEL에 입력하지 마십시오.

HITEL 계정 추가 · 전환 · 삭제

이 화면은 HITEL 브라우저 시험 프로필을 관리합니다. 실제 Google 계정이나 ChatGPT 로그인 계정을 추가·전환·삭제하지 않습니다.

계정 전환 시 해당 프로필의 방과 파일만 표시됩니다. 삭제하면 해당 시험 프로필의 대화방·파일이 영구 삭제됩니다. 실제 ChatGPT 로그인은 바뀌지 않습니다.
