ChatGPT 계정 2개 · 원격 Chrome 최초 로그인

최초 한 번만 GitHub Actions에서 실행되는 실제 Chrome에 계정 A와 B를 각각 로그인하시면 됩니다. 이메일과 비밀번호는 Google 또는 OpenAI의 공식 로그인 화면에 직접 입력하시며, HITEL 서버는 비밀번호를 받지 않습니다.

① GitHub Actions 원격 Chrome 실행

버튼을 누르셔서 GitHub의 Run workflow를 실행해 주십시오. 이 작업은 임시 GitHub 컴퓨터에서만 Chrome을 시작합니다.

GitHub에서 원격 Chrome 시작
현재 실행 가능한 원격 Chrome 링크를 확인하고 있습니다.
계정 A·B 로그인 화면 열기

원격 화면은 기존에 사용하시던 개인 접속 코드로 보호됩니다. 코드나 Google 비밀번호를 GitHub 실행 로그·채팅창에 입력하지 마십시오.

② 원격 화면에서 두 계정 로그인

계정 A

1. 원격 Chrome에서 첫 번째 Google/ChatGPT 계정으로 로그인

2. 화면의 A 로그인 확인·저장 선택

3. 실제 ChatGPT 로그인 검증 후 A 전용 Chrome 프로필 암호화

계정 B

1. 원격 화면이 B 전용 Chrome으로 바뀌면 두 번째 계정 로그인

2. 화면의 B 로그인 확인·저장 선택

3. A와 다른 계정임을 확인한 뒤 B 전용 프로필 암호화

③ 이후에는 저장된 세션 재사용

두 프로필은 별도 암호화 파일로 저장됩니다. Chrome 세션이 유효한 동안에는 매번 비밀번호를 입력할 필요가 없습니다. Google/OpenAI가 재인증을 요청하면 해당 계정을 다시 직접 로그인해야 합니다.

GitHub Actions 암호화 아티팩트의 기본 저장기간은 이번 워크플로 설정상 90일이며, 실제 로그인 유지기간과는 다릅니다. 저장파일 만료 이전에는 갱신이 필요합니다.
