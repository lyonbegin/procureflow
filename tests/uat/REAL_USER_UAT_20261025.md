# ProcureFlow 실제 사용자 브라우저 UAT 점검표

테스트 일자: 2026-10-25. 실서비스: https://procureflow-api-production.up.railway.app/flow

**정의:** `PASS` = 브라우저에서 직접 조작해서 확인, `FAIL` = 조작 오류 재현, `BLOCKED` = TinyFish·운영 인증·환경 문제로 조작 미실시, `NOT_RUN` = 실행하지 않음. API 테스트나 소스 빌드만으로 PASS 처리 금지.

**테스트 절차:** 무인증 읽기 전용 항목은 실제 Railway 페이지에서 Playwright Chromium 실행 및 스크린샷·콘솔 오류를 저장한다. 인증이 필요한 생성·편집·파일 업로드·디버거는 유효한 사용자/테스트 계정이 연결된 브라우저에서만 실행한다. 실제 발주 증빙과 DB가 변형될 수 있는 업무 기능의 자동 수집·입찰 제출은 실행하지 않는다.

## 결함 보고 양식

- 테스트 ID
- 접속 URL / 브라우저 / 화면 크기
- 시작 상태(발주번호, 활성 그래프, 관리자 인증 유무)
- 수행한 실제 마우스·키보드 조작
- 기대한 변화 vs 화면에서 실제 관찰한 변화
- 콘솔 오류, 네트워크 HTTP 상태
- 실패 화면 스크린샷 경로
- 심각도(P0: 조작 불가/데이터 훼손, P1: 기본 기능 실패, P2: UI 혼란)
- 재현률(예: 3/3) 및 수정 필요 파일

## TinyFish 연결

TinyFish 플러그인 연동은 이 대화에서 별도로 승인·연결해야 하며 현재 설치되지 않았다. 설치·연결 전에는 TinyFish로 테스트했다는 주장을 하지 않는다. TinyFish 연결과 무관하게 GitHub Actions에서 Chromium을 사용한 **비인증 실서비스 화면 테스트**는 수행 가능하다.
